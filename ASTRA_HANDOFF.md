# Handoff for Astra: pixel Winnie poses

Completed 2026-10-13: the poses are generated and wired into the room. Sources,
generation brief and reproducible packing instructions are in
`assets/animation/README.md`; the runtime uses `winnie-room-v3.png`.
The original generation brief below is retained for reference.

You are making new pixel-art frames of Winnie, a small apricot cavapoo, for the room on the Today screen of this app. A script then cleans your frames into the room's pixel grid. Read this whole file before generating anything.

## The character (match exactly)

- Reference image: `public/photos/winnie-pixel-v2.png` (3 columns x 2 rows of 128 px cells: sit, blink, sleep / walk A, walk B, happy). Use it as the image reference for every generation.
- Small apricot cavapoo: fluffy curly coat, long wavy ears, dark round eyes, dark nose, plume tail that curls up.
- Blue and white gingham bandana, always on.
- Same pixel size, palette, dark brown outline, proportions, and three-quarter view as the reference. If a frame comes out a different size, angle, or art style, regenerate it; the room breaks when his size jumps between frames.

## Frame format

- 128 x 128 px per cell, transparent background, no ground shadow, no text.
- Winnie centered in each cell, same size as the reference, feet on the same baseline about 8 px from the bottom of the cell. Lying poses rest on that same baseline.
- Facing: same as the reference for each kind of pose (sitting and lying poses face the viewer at three-quarter; moving poses face right). The app mirrors frames for the other direction.
- Sheets are 3 columns wide, so each sheet is 384 px wide and 128 px per row.

## What to make

These are the poses that can't be derived from his existing frames. Animation pairs need both frames to line up exactly except for the moving part.

## Where to put files

- Save raw sheets to `assets/astra/winnie-poses-a.png` and `assets/astra/winnie-poses-b.png`.
- Do not edit or overwrite anything in `public/`. The app's current sheet, `public/photos/winnie-room-v2.png`, is generated by `scripts/build-poses.mjs`.

## After generating (for the developer, not Astra)

1. Clean each sheet into the room's 64 px grid:
   `node scripts/clean-sprite.mjs assets/astra/winnie-poses-a.png public/photos/winnie-room-poses-a.png 64`
2. Look at the output zoomed in. Check the bandana is still blue and his size matches the existing frames.
3. Ask Claude to wire the new frames into `public/room.js` (FRAMES and the behaviours that use them).

## The one rule every pose must follow

The room shows only what was logged and the time of day. Winnie never looks sad, hungry, sick, impatient, or in trouble. No crying, no drooping ears, no empty-bowl staring. Calm, happy, curious, sleepy, and silly are all fine.
