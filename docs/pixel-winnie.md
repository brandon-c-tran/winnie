# Pixel Winnie, first iteration

The companion supplements Winnie's real photos. It rests below the Today introduction, curls up when a sleep entry is active, and briefly cheers after a log or a tap. It never reports sync status or a health assessment. Reduced-motion preferences disable the bounce and heart motion.

Asset: `public/photos/winnie-pixel-v1.png`, three equal frames (awake, sleeping, happy). Generated with the built-in image-generation tool using `public/photos/winnie-story.png` as the appearance reference. The source photograph is preserved.

## Final prompt

Use case: style-transfer. Asset type: transparent pixel-art sprite sheet for Winnie's personal care app. Transform the dog in the reference photo into a tiny, charming 2D pixel-art companion. Reference image is ONLY for Winnie's appearance: a male apricot/cream Cavapoo, fluffy round curly head, long caramel floppy ears, black button nose, dark eyes, blue-and-white gingham bandana. Keep him recognizably this dog. Make ONE horizontal sprite sheet, exactly 3 equal square cells side by side (3:1 aspect ratio). Left cell: sitting awake, facing slightly right, relaxed smile, tail visible. Middle cell: the same dog curled up asleep, eyes shut, nose on paws. Right cell: same dog sitting happily with eyes smiling and tail raised, tiny pink tongue. All cells: same character proportions, same limited warm cream/apricot/chocolate/soft blue palette, crisp square pixels like a carefully drawn 48x48 game sprite enlarged with nearest-neighbor, no smooth or vector outlines, no antialiasing, no painted textures. Each character fully inside its own square cell with generous transparent margin, centered horizontally, paws on the same baseline at 85% of cell height. Transparent alpha background everywhere outside the dog, including between frames. No checkerboard drawn into pixels, no floor, no scenery, no text, no letters, no icons, no border, no shadows. This is an accessory to real dog photography in a calm cream-and-green app.
